# Ordenar lista de nombres

Una pequeña aplicación web en JavaScript para ingresar nombres, ordenarlos alfabéticamente y mostrarlos en una lista.

## Funcionalidades
- Agregar nombres desde un formulario
- Ordenar automáticamente la lista
- Validar que el campo no quede vacío
- Validar que el nombre no contenga números
- Mostrar mensajes de éxito o error
- Botón para limpiar la lista
- Diseño moderno con hover, animaciones y responsive design

## Archivos
- `index.html` o `reto_3.html`: estructura de la página
- `app.js`: lógica del programa
- `styles.css`: estilos visuales

## Cómo usarlo
1. Abre el archivo `reto_3.html` en el navegador.
2. Escribe un nombre en el campo.
3. Haz clic en "Agregar".
4. La lista se ordenará alfabéticamente.
5. Usa "Limpiar" para borrar la lista.

## Validaciones
- Si dejas el campo vacío, mostrará un mensaje de error.
- Si introduces números, también mostrará un mensaje de error.

## Requisitos
- Navegador moderno con soporte de JavaScript.
